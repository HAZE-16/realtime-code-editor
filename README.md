# Realtime Code Editor

A real-time collaborative code editor where multiple users can write and edit code together — live, in the same room.

## Features
- Real-time collaboration — see changes as others type
- Multi-language syntax highlighting
- Room-based sessions — share a room ID to collaborate
- Clean and minimal editor UI

## How to run locally

```bash
# Clone the repo
git clone https://github.com/HAZE-16/realtime-code-editor.git

# Go into the folder
cd realtime-code-editor

# Install dependencies
npm install

# Start the app
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
